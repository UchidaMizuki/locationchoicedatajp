# Files of the railway stations

`rail_station_files()` lists the file of each year of
[`rail_station_get()`](https://uchidamizuki.github.io/locationchoicedatajp/reference/rail_station_get.md):
the release of 鉄道 (N02) in
[ksjdata::ksj_available](https://rdrr.io/pkg/ksjdata/man/ksj_available.html),
its layer of stations, the EPSG code of its coordinate reference system,
the number of stations, and its URL. It is used by the bundled pipeline.

## Usage

``` r
rail_station_files()
```

## Value

A tibble with columns `year`, `file_name`, `layer`, `epsg`,
`n_stations`, and `url`.
