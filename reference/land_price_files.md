# Files of the land prices

`land_price_files()` lists the file of each year of
[`land_price_get()`](https://uchidamizuki.github.io/locationchoicedatajp/reference/land_price_get.md):
the nationwide file of that year's release of 地価公示 (L01) in
[ksjdata::ksj_available](https://rdrr.io/pkg/ksjdata/man/ksj_available.html),
with the columns that hold the municipality, the use, the serial number,
and the price, the EPSG code of its coordinate reference system, and the
number of sites. The layout of the files changes between releases, so
the columns are listed for each one. It is used by the bundled pipeline.

## Usage

``` r
land_price_files()
```

## Value

A tibble with one row per year: `year`, `file_name`, the columns
`city_code`, `use_code`, `site_number`, and `price`, `epsg`, `n_points`,
and the `url` of the file.
