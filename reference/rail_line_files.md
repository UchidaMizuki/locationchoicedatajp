# Files of the railway lines

`rail_line_files()` lists the file of each year of
[`rail_line_get()`](https://uchidamizuki.github.io/locationchoicedatajp/reference/rail_line_get.md):
the release of 鉄道 (N02) in
[ksjdata::ksj_available](https://rdrr.io/pkg/ksjdata/man/ksj_available.html),
its layer of sections of lines, the EPSG code of its coordinate
reference system, the number of sections, and its URL. It is used by the
bundled pipeline.

## Usage

``` r
rail_line_files()
```

## Value

A tibble with columns `year`, `file_name`, `layer`, `epsg`,
`n_sections`, and `url`.
