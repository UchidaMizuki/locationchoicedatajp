# locationchoicedatajp: Open Data for Location Choice Models in Japan

Provides reproducible pipelines that build analysis-ready tables for
estimating household and firm location choice models in Japan from open
data published by the national government. Data are not bundled: they
are downloaded from the primary sources and built on demand by 'targets'
pipelines bundled with the package, and cached via 'tarchives'.
